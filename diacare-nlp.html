THE APPROACH

Small, focused, and explainable.

01

Check high-risk phrases

A keyword gate runs first. Matching phrases bypass the models and trigger a priority-5 medical escalation.

02

Classify the request

Two calibrated linear SVM models predict the support category and priority from TF-IDF text features.

03

Return a clear response

FastAPI returns the category, priority, confidence field, and reason phrases for review by a person.

WHAT IT COVERS

Support routing.
Not diagnosis.

Five categories: appointment, billing, medical, technical issue, and other. Priority runs from 1 (low) to 5 (emergency).

The project uses 630 synthetic messages. It contains no patient records or personal health information. The keyword gate covers only a small set of phrases and cannot replace clinical assessment.

How it was evaluated

A stratified 20% holdout leaves 126 messages for testing. Five-fold stratified cross-validation is performed on the remaining training pool, using random seed 42. Features include TF-IDF unigrams and bigrams, with up to 20,000 features. The linear SVM models use sigmoid probability calibration; priority uses balanced class weights.

Macro F1 weights each class equally. The technical-issue category has lower recall (80%) than the other categories. Priority 5 has only seven holdout examples, so conclusions about rare urgent cases need particular care.

What the API provides

POST /triage accepts message text. GET /health reports service status and whether the models loaded. The repository includes training code, model artifacts, Docker packaging, and API and safety-gate tests.

For model predictions, the returned confidence field is the larger of the category and priority model’s maximum probabilities—not a joint certainty score. The gate’s 0.99 value is fixed by code, not an estimated clinical probability.

Before real-world use

The category-balanced synthetic dataset does not represent real support traffic. Representative validation and review by qualified professionals would be required before real-world use.
